# skills/inbox/workflows/

The five workflows `SKILL.md` dispatches to, one file per job the user asks
for.

- `triage.md` -- classify ONE pasted thread and log it.
- `backlog-sweep.md` -- a pile, not one thread; a month of email ranked by
  dollars at risk.
- `draft-reply.md` -- write the reply in the user's voice; the human sends it.
- `whos-waiting.md` -- the daily "who am I ghosting?" report.
- `follow-up-report.md` -- the branded page they can print, show, or bring to a
  Monday huddle.
